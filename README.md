# Academic Course Planner
A personal tool I built to manage the complexity of planning a multi-year 
Industrial Engineering & Information Systems degree — tracking prerequisites, 
balancing credit load across semesters, and optimizing my weekly schedule.

## Why I built this
Planning a degree with dozens of courses, prerequisite chains, and flexible 
semester options quickly became too complex to track manually. I wanted a 
tool that could show me the full picture and help me make better decisions 
about when to take each course.

## What it does
- **Drag-and-drop semester planning** — organize courses across semesters 
  while automatically tracking prerequisite dependencies
- **Credit-load balancing** — get recommendations for redistributing courses 
  to avoid overloaded semesters
- **Schedule optimization** — compress study days by identifying which 
  lectures/labs can be consolidated
- **Progress tracking** — real-time view of completed vs. required credits 
  by category and track

## How I built it
I defined the core logic myself — the prerequisite rules, the balancing 
priorities, and the overall user experience — and used AI-assisted 
development (Claude) to implement it. This let me focus on the actual 
planning problem rather than on writing every line of code, while still 
making all the product and logic decisions.
